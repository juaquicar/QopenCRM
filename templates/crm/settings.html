Asistente de IA (MCP)

Conecta tu asistente (Claude u otro compatible con MCP) y pídele las cosas con tus palabras: «¿qué tengo para hoy?», «crea un lead de Fibranet con Plan Pro», «anota que he llamado a Marta». Trabaja con tus permisos de {{ user.role_name }}: {{ mcp_tools|length }} herramientas.

Dirección
{{ mcp_url }}
Conectarlo desde Claude (web, escritorio o móvil)
  1. En Claude: Ajustes → Conectores → Añadir conector personalizado.
  2. Pega la dirección de arriba. No hace falta ninguna clave.
  3. Se abre el CRM: entra con tu correo y pulsa Autorizar.
Conectarlo con clave (Claude Code y otros)

Crea una clave en «Mis claves de API». Claude Code:

claude mcp add --transport http qopencrm {{ mcp_url }} --header "Authorization: Bearer TU_CLAVE"

Otros clientes (fichero de configuración MCP):

{"mcpServers": {"qopencrm": {"type": "http", "url": "{{ mcp_url }}",
  "headers": {"Authorization": "Bearer TU_CLAVE"}}}}
